# Распознавание техпаспортов → данные для CRM

Автоматизация ООО «Палладиум – арт»: сотрудник фотографирует свидетельство о регистрации ТС,
получает готовые значения полей и копирует их в форму total-service.by.

## Что внутри

| Файл | Назначение | Нужен Excel |
|---|---|---|
| `tg_bot.py` | Telegram-бот: фото → распознавание → карточка с кнопками копирования | нет |
| `scan_cars.py` | пакетная обработка папки с фото, дозапись в `Автомобили.xlsx` | да |
| `car_registry.py` | правила проверки (VIN, номер, год, дубли) и работа с реестром Excel | только для реестра |
| `run_bot.cmd` | запуск бота с автоперезапуском | нет |
| `scan_cars.cmd` | запуск пакетной обработки | да |

## Требования

- Python 3.10 или новее.
- Для бота дополнительных пакетов **не требуется** — только стандартная библиотека.
- Для пакетной обработки в Excel: `py -m pip install openpyxl`.
- По желанию: `pillow` (уменьшение фото перед отправкой), `pymupdf` (приём PDF-сканов).

## Секреты

Токен бота и ключ модели **не хранятся в репозитории** (см. `.gitignore`). Любой из вариантов:

| Что | Вариант 1 | Вариант 2 |
|---|---|---|
| Токен Telegram | переменная `TELEGRAM_BOT_TOKEN` | файл `tools/.tg_token` |
| Ключ DeepSeek | переменная `DEEPSEEK_API_KEY` | файл `tools/.deepseek_key` |

Права: только владелец, никому не пересылать. Если токен утёк — @BotFather → `/revoke`.

## Запуск бота

```powershell
# из папки tools
.\run_bot.cmd
```

Или напрямую `py tg_bot.py`. Останавливается закрытием окна или Ctrl+C.

Настройки — `tg_config.json` (образец: `tg_config.example.json`):

```json
{"allowed_chat_ids": [5085693770], "max_per_minute": 3}
```

`allowed_chat_ids` — кто имеет доступ. Пустой список означает «никого»: бот отвечает
chat_id и просит администратора добавить его в список. После правки файла бота нужно перезапустить.

## Проверка без Telegram

```powershell
py tg_bot.py --test-photo "C:\путь\к\фото.jpg"
```

Печатает ровно то сообщение, которое уйдёт в чат.

## Пакетная обработка в Excel

```powershell
.\scan_cars.cmd "D:\Фото авто" --dry-run   # только показать
.\scan_cars.cmd "D:\Фото авто"             # записать в реестр
```

Реестр должен быть закрыт в Excel, иначе скрипт честно откажется работать.

## Журналы

`tools/logs/tg_bot.log` и `tools/logs/scan_cars.log` — с датой, временем и всеми ошибками.
Файлы не попадают в репозиторий.

## Что распознаётся

Из свидетельства берутся: марка, модель, VIN, государственный номер, год выпуска,
объём двигателя и модель двигателя (если напечатаны), цвет, массы, владелец, лизингодатель.

Правила:

- VIN — ровно 17 знаков, только латиница и цифры, без I/O/Q;
- кириллические двойники латинских букв в номере и VIN приводятся к латинице
  (`А 0926 Е-1` → `A 0926 E-1`);
- год выпуска сверяется с 10-м знаком VIN — расхождение выводится предупреждением
  (у прицепов кодировка часто нестандартная, поэтому это не блокирует запись);
- если поле не читается, оно **не выдумывается**, а остаётся пустым и попадает в `unreadable`.

## Ограничения

- Фотографии уходят в облако DeepSeek: это персональные данные владельцев ТС.
- Бот работает, пока запущен процесс и включён компьютер.
- Модель иногда тратит весь лимит токенов на рассуждение — в этом случае бот повторяет запрос
  с удвоенным лимитом, а при повторной неудаче честно сообщает об ошибке.
